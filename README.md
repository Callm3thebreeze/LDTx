# LDTx - Web Estática con Astro

Proyecto de web estática desarrollado con Astro, TypeScript y TailwindCSS, optimizado para SEO con secciones de blog y productos.

## Estructura del Proyecto

```
/                     → Home: mensaje claro + acceso rápido a blog y catálogo
/blog/                → Listado de artículos por categoría
/blog/cocina/         → Artículos relacionados con cocina saludable
/blog/cocina/sartenes-sin-teflon → Artículo concreto
/productos/           → Catálogo de productos saludables (afiliados)
/productos/cocina/    → Productos de cocina saludables
/productos/cocina/sartenes/ → Filtros + productos
/producto/nombre-producto/ → Página individual optimizada por keyword
/quienes-somos        → Autoridad / transparencia / confianza
/contacto             → Contacto / privacidad / política de afiliación
```

## Comandos

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Previsualiza la build

## Tecnologías

- Astro
- TypeScript
- TailwindCSS
- Optimización SEO
